The Tweaks Anthology Helper Tool

THIS IS NOT A CONTENT MOD FOR PLAYERS. This is a tool to help Tweaks Anthology keep its armor list up-to-date. If you have a heavily modded game, run this tool and email the specified folder to the address provided in the mod. No changes will be made to your game.

Being able to tell different types of armor from one another is difficult to do automatically—the same goes for shields—and that's not accounting for all of the interesting effects (such as full plate without casting or thieving penalties) that some mods can use. As such, some Tweaks Anthology components rely on static lists of armors and shields for its changes. The problem is that the community is incredibly prolific and its near impossible to keep up. Enter this tool!

Run this against your heavily modified install and the tool will identify any armor or shield not already on Anthology's patch list—alongside other relevant information—to be submitted to CamDawg. Logs and items files will be compiled into the

weidu_external/cdtweaks_helper/email_to_cam

folder. Just zip that up and get it to CamDawg via Discord, email, forum post, whatever.

While this is a WeiDU-based tool, no actual changes will be made to your game and it won't show up in your weidu.log.
